# Social Media Operations Dashboard

A dashboard for running several social media accounts from one place: which
accounts exist, what each one is for, and what needs attention.

## Status

**Early stage. No code yet.** The account list is currently kept in a
spreadsheet. This repository is where the dashboard that replaces it will live.

## Planned

- One list of every account, with platform, handle, purpose and owner
- Per-account status and notes
- A simple overview of what needs attention this week
